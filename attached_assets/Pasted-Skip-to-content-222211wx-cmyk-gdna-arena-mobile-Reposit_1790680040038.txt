إيه، دابا هاد الـlog وضّح المشكل: البناء وقف قبل ما يوصل لـGradle.

الأمر npx expo prebuild ما لقا حتى تثبيت ديال Expo فالمجلد اللي خدام فيه، وحاول يحمّلو مؤقتاً. فالمشروع ديالك، تطبيق Expo موجود هنا:

artifacts/gdna-arena-mobile
يعني خاصنا نثبّتو dependencies من جذر المستودع، ومن بعد نشغّلو Expo من مجلد التطبيق وبـpnpm exec. وزيد نحيدو --non-interactive ونعوّضوه بـCI: 'true'.

عوّض محتوى .github/workflows/build.yml كامل بهاد النسخة:

name: Build APK
on:
  push:
    branches: [main]
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-24.04
    timeout-minutes: 60
    permissions:
      contents: read
    env:
      CI: 'true'
      NODE_OPTIONS: --max-old-space-size=4096
      EXPO_PUBLIC_API_ORIGIN: https://helixly.app
      EXPO_PUBLIC_DOMAIN: helixly.app
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with:
          version: 10.26.1
      - uses: actions/setup-node@v5
        with:
          node-version: 22
          cache: pnpm
          cache-dependency-path: pnpm-lock.yaml
      - uses: actions/setup-java@v5
        with:
          distribution: temurin
          java-version: '17'
      - name: Install workspace dependencies
        run: pnpm install --frozen-lockfile --prod=false
      - name: Verify installed Expo
        working-directory: artifacts/gdna-arena-mobile
        run: |
          node --print "require.resolve('expo/package.json')"
          pnpm exec expo --version
      - name: Generate Android project
        working-directory: artifacts/gdna-arena-mobile
        run: pnpm exec expo prebuild --platform android --clean --no-install
      - name: Configure Android SDK
        working-directory: artifacts/gdna-arena-mobile
        run: |
          SDK_PATH="${ANDROID_HOME:-${ANDROID_SDK_ROOT:-}}"
          if [[ -z "$SDK_PATH" || ! -d "$SDK_PATH" ]]; then
            echo "::error::Android SDK not found"
            exit 1
          fi
          printf 'sdk.dir=%s\n' "$SDK_PATH" > android/local.properties
      - name: Build APK
        working-directory: artifacts/gdna-arena-mobile/android
        run: |
          chmod +x gradlew
          ./gradlew --version
          ./gradlew assembleRelease --no-daemon --stacktrace --info --console=plain
      - name: Upload APK
        uses: actions/upload-artifact@v4
        with:
          name: gdna-arena-apk
          path: artifacts/gdna-arena-mobile/android/app/build/outputs/apk/release/*.apk
          if-no-files-found: error
ما تحتاجش تزيد npm install expo ولا تبدّل app.json بسبب هاد الخطأ؛ Expo راه معلن عليه فـpackage.json ديال التطبيق. المشكل الظاهر هنا هو الوصول ليه أثناء البناء.

هاد التصحيح كيعالج الخطأ اللي صيفطتي، ولكن نجاح الـAPK كامل خاصّو يتأكد من التشغيل الجاي. ما طبّقتش هاد النسخة على GitHub من جهتي.
