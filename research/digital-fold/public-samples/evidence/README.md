# Source and permission evidence

These Markdown snapshots preserve the Commons file-description pages fetched
on 2026-10-03 for the six added works. Each snapshot links its source and
reported page revision; the manifest selects the license and provides the
required attribution separately for each work. Page text is Wikimedia Commons
content; see https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia
and https://creativecommons.org/licenses/by-sa/4.0/ for page-text reuse terms.
Media licenses are file-specific, not inherited from the page-text license.

The actual measured inputs are the complete **Original file** downloads, not
the thumbnails or playback transcodes. Original here means the Commons upload:
the panorama was stitched upstream and the rain Ogg originated from an MP3.
No image, audio or video was transformed for this research. Different files
represent independent works, not recoded or repeated versions of one source.

The speech page identifies an official-duty US federal government work but
does not identify the individual recordist; the manifest preserves that
limitation rather than inventing an author or a worldwide dedication.
The workshop video page carries a personality-rights warning, also preserved
in the manifest. Inclusion is for compression research, not endorsement.
Preserve these notices, author credits and license links on redistribution.

Byte counts and SHA-256 values pin the downloaded files. The page snapshots
document permission statements, not proof of copyright ownership. Upstream
replacement must fail the benchmark's size/hash validation.
